# کتابخانه رسانه (Admin)

مسیر: **`/admin/media`** — «رسانه‌ها» در منوی محتوا.

## قابilities

- آپلود تک‌فایلی (JPEG / PNG / WebP) با اعتبارسنجی امضای فایل در سرور
- لیست صفحه‌بندی‌شده با جستجو
- جزئیات هر رسانه (ابعاد، حجم، alt، زمان ایجاد)
- **بدون حذف** در نسخهٔ v1

## Content Studio

- **تصویر کاور:** دکمه «انتخاب از رسانه‌ها» → `CoverImage` = `PublicUrl` انتخاب‌شده
- **تصویر OG (سئو):** همان picker برای `OgImage`
- ورود دستی URL همچنان پشتیبانی می‌شود
- انتخاب **ذخیره خودکار نمی‌کند** — وضعیت «ذخیره نشده» و گزارش سئو **کهنه** می‌شود

## محدودیت‌ها

- SVG و فایل‌های غیرتصویری پذیرفته نمی‌شوند
- بدون CDN / S3 / تولید تصویر با AI
- بدون ویرایش، برش، یا بهینه‌سازی خودکار

جزئیات فنی: `api/docs/media/media-module.md`.
